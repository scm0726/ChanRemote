접속 비밀번호

다른 기기에서 접속할 때 입력할 비밀번호예요. 8자 이상, 숫자·영문을 섞으면 안전해요.

다른 PC 원격 접속

다른 PC의 ID와 비밀번호로 그 PC를 조작해요.

관리자(마스터) 비밀번호

내 모든 PC에 같은 마스터 비밀번호를 넣어 두면, 폰·다른 PC에서 관리자 로그인 한 번으로 ID 없이 전부 목록에 떠요. (선택 사항)
