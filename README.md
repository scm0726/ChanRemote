# ChanRemote — 나만의 원격 제어

PC 프로그램 하나 + 폰 앱 하나로 집 PC를 어디서든 조작하는 프로그램이에요.

- **PC ↔ 폰(갤럭시 폴드 등)**: 안드로이드 앱
- **PC ↔ PC**: 다른 PC의 크롬/엣지에서 `http://PC주소:8787` 접속
- **집 와이파이 / 밖(LTE·회사)** 모두 지원 — 등록한 주소 중 되는 곳으로 자동 연결

## 설치

1. GitHub 저장소의 **Releases**에서 최신 버전을 받아요.
   - PC: `ChanRemote-Setup-x.x.x.exe`
   - 폰: `ChanRemote.apk`
2. **PC**: 설치 파일 실행 → (파란 경고창이 뜨면) **추가 정보 → 실행** → 관리자 권한 **예**.
   설치할 때 윈도우 방화벽 허용도 자동으로 해요.
3. PC 프로그램이 뜨면 **접속 비밀번호**를 정해요.
4. **폰**: APK 실행 → "출처를 알 수 없는 앱 설치 허용" → 설치.
5. 앱에서 **PC 추가** → PC 화면에 나온 주소(예: `192.168.0.10`)와 비밀번호 입력 → 연결.
   한 번 연결하면 외부 주소도 자동으로 저장돼서, 밖에서도 같은 버튼으로 연결돼요.

## 폰 조작법

| 동작 | 터치패드 모드 (기본) | 직접 터치 모드 |
|---|---|---|
| 커서 이동 | 한 손가락으로 밀기 | 누른 곳으로 이동 |
| 클릭 | 탭 | 탭 |
| 더블클릭 | 두 번 탭 | 두 번 탭 |
| 우클릭 | 두 손가락 탭 / 길게 누르기 | 길게 누르기 |
| 드래그 | 탭 후 바로 누른 채 밀기 | 누른 채 밀기 |
| 스크롤 | 두 손가락으로 밀기 | 두 손가락으로 밀기 |
| 화면 확대 | 두 손가락 벌리기 | 두 손가락 벌리기 |
| 키보드 | 세 손가락 탭 또는 ⌨ 버튼 | 같음 |

- **특수키(⌘)**: Esc, 한/영, 방향키, F1~F12, 복사/붙여넣기, 창 전환, 작업관리자 등
- **Ctrl·Alt·Shift·Win**: 한 번 누르면 켜지고, 다음 키를 누르면 자동으로 꺼져요 (예: Ctrl → c = 복사)
- **설정(⚙)**: 화질(자동/고화질/절약/저속), 커서 속도, PC 소리, 클립보드 주고받기

## 끊김 방지

- 연결이 흔들리면 1.5초 안에 자동 복구, 안 되면 연결을 새로 만들어요.
- 와이파이 ↔ LTE가 바뀌어도 자동으로 다시 붙어요 (접속 서버가 끊겨도 30초 동안 세션 유지).
- 직접 연결이 막힌 통신망에서는 PC에 들어 있는 **중계 서버**를 거쳐서 연결해요.
- PC: 접속 중 화면 꺼짐 방지, 절전 방지, 윈도우 시작 시 자동 실행, 트레이 상주.
- 끊기는 순간 눌려 있던 키/마우스 버튼은 자동으로 떼요.

## 외부 접속 (LTE·회사)

PC 프로그램이 공유기 포트를 자동으로 열어요(UPnP). PC 화면의 **외부 접속** 칸이 초록색이면 준비 끝이에요.

빨간색이면:
- 공유기 관리 페이지에서 **UPnP 켜기** (ipTIME: 고급 설정 → 네트워크 관리 → UPnP)
- 또는 **포트포워딩** 직접 추가: `TCP 8787`, `UDP 3478`, `TCP 3478` → PC 내부 IP
- **이중 NAT**(공유기 두 대)라고 나오면 바깥쪽 공유기에도 같은 포트포워딩이 필요해요.

> 집 인터넷 공인 IP는 가끔 바뀌어요. 바뀌면 집 와이파이에서 앱으로 한 번 접속하면 새 주소를 자동으로 배워요.
> ipTIME DDNS(예: `myhome.iptime.org`)를 쓰면 앱에 그 주소를 추가해 두면 돼요.

## 보안

- 비밀번호는 네트워크로 보내지 않아요 (일회용 값에 대한 증명만 보냄). PC에도 원문 대신 변환된 값만 저장해요.
- 비밀번호 5번 틀리면 5분간 잠겨요.
- 화면·소리·입력은 WebRTC(DTLS-SRTP)로 암호화되고, 연결 정보는 비밀번호에서 만든 키로 서명해서 중간에서 바꿔치기할 수 없어요.
- 내장 중계 서버는 이 PC로만 중계해요 (다른 곳으로 악용 불가).
- PC에서 비밀번호를 바꾸면 기존 접속은 모두 끊겨요.

## 알아둘 점

- 윈도우 **잠금화면, 관리자 권한 창(UAC)** 은 윈도우 보안 정책상 조작할 수 없어요. 원격으로 쓸 PC는 잠금 없이 두세요.
- 관리자 권한으로 실행한 프로그램을 조작하려면 ChanRemote도 관리자 권한으로 실행해야 해요.
- Ctrl+Alt+Del은 보낼 수 없어요 → 특수키의 **작업관리자** 버튼을 쓰세요.

## 구조 (개발용)

```
src/            PC 프로그램 (Electron)
  main.js         트레이, 설정, 입력 처리, 네트워크 확인
  server.js       접속 서버 (인증, 시그널링, 뷰어 웹 제공)
  turn.js         내장 중계(TURN) 서버
  upnp.js         공유기 자동 포트 열기
  input.js        마우스/키보드 입력 (Windows SendInput)
  host/           PC 창 화면 + 화면 캡처·WebRTC 송신
web/            뷰어 (PC 브라우저 접속용 + 안드로이드 앱 안에 그대로 들어감)
android-app/    안드로이드 앱 빌드 설정 (Capacitor)
.github/        GitHub에 올리면 exe·apk 자동 빌드
```

직접 빌드: `npm install` → `npm start`(실행) / `npm run build`(설치 파일). APK는 `android-app/build-apk.sh` (JDK 21 + Android SDK 필요).

설정 파일: `%APPDATA%\ChanRemote\config.json` (포트, 외부 TURN 등)
