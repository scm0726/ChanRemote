# ChanRemote — 나만의 원격 제어

**설치만 하면 끝.** 가입·키·포트포워딩 없이, PC ID와 비밀번호로 어디서든 접속해요 (애니데스크 방식).

- **PC 프로그램 하나**: 내 PC 원격 받기 + 다른 PC에 원격 접속하기
- **폰 앱 하나**: PC 목록(켜짐/꺼짐 표시)에서 눌러서 바로 접속
- **무인 접속 기본**: 자리에 아무도 없어도 수락 없이 바로 접속

## 설치

GitHub 저장소의 **Releases**에서 받아요.

1. **PC**: `ChanRemote-Setup-x.x.x.exe` 실행 → (파란 경고창) **추가 정보 → 실행** → 관리자 권한 **예**
2. PC 프로그램에 나온 **9자리 PC ID**를 확인하고 **접속 비밀번호**를 정해요 (8자 이상 권장).
3. **폰**: `ChanRemote.apk` 설치 → **PC 추가** → PC ID + 비밀번호 → 연결
4. **다른 PC에서**: 같은 프로그램을 설치하고 **원격 접속 창 열기** → PC ID + 비밀번호

## 연결 방식

```
PC 프로그램 ──바깥으로 접속──▶ 공개 중계망(MQTT, 3곳 동시) ◀──바깥으로 접속── 폰 앱
        └──────────── 서로 찾은 뒤 화면은 직접(P2P) 전송 ────────────┘
```

- 둘 다 **바깥으로만** 접속하므로 공유기 설정이 필요 없어요.
- 공개 중계망은 가입 없이 쓰는 무료 서버(EMQX, HiveMQ, Mosquitto)이고, 3곳에 동시에 붙어서 한 곳이 멈춰도 계속 동작해요.
- 직접 연결이 막힌 엄격한 통신망에서는 **PC가 공유기 문을 자동으로 열고(UPnP) 스스로 중계**해요.
- 같은 와이파이에서는 더 빠른 직접 경로를 자동으로 함께 시도해요.

## 무인 접속 (기본 켜짐)

- 절전 모드, 자동 화면 잠금, 화면보호기 잠금을 자동으로 꺼요.
- 접속하면 꺼진 모니터를 자동으로 깨워요.
- 누가 접속하면 PC에 알림이 떠요.
- **재부팅 대비**: 윈도우 자동 로그인을 설정해 두면 재부팅 뒤에도 바로 접속돼요 (`Win+R` → `netplwiz`).

## 폰 조작법

| 동작 | 터치패드 모드 (기본) | 직접 터치 모드 |
|---|---|---|
| 커서 이동 | 한 손가락으로 밀기 | 누른 곳으로 이동 |
| 클릭 / 더블클릭 | 탭 / 두 번 탭 | 탭 / 두 번 탭 |
| 우클릭 | 두 손가락 탭 · 길게 누르기 | 길게 누르기 |
| 드래그 | 탭 후 바로 누른 채 밀기 | 누른 채 밀기 |
| 스크롤 · 확대 | 두 손가락 밀기 · 벌리기 | 같음 |
| 키보드 | 세 손가락 탭 또는 ⌨ | 같음 |

특수키(⌘): Esc, 한/영, 방향키, F1~F12, 복사/붙여넣기, 창 전환, 작업관리자 등. Ctrl·Alt·Shift·Win은 한 번 누르면 다음 키에 적용돼요.

## 보안

- 비밀번호는 네트워크로 보내지 않아요. PC에도 원문 대신 변환된 값(PBKDF2)만 저장해요.
- 공개 중계망으로 오가는 내용은 **비밀번호로 만든 키로 전부 암호화**돼요. 중계망 운영자도 내용을 볼 수 없어요.
- 화면·소리·입력은 WebRTC(DTLS-SRTP)로 암호화돼요.
- 비밀번호를 5번 틀리면 5분간 잠겨요. 비밀번호는 **8자 이상, 숫자·영문 섞어서** 쓰세요.

## 알아둘 점

- 윈도우 **잠금화면·로그인 화면·관리자 권한 창(UAC)** 은 조작할 수 없어요 (무인 접속 모드가 잠금을 막아 줘요).
- Ctrl+Alt+Del은 보낼 수 없어요 → 특수키의 **작업관리자** 버튼을 쓰세요.

## 구조 (개발용)

```
src/            PC 프로그램 (Electron)
  main.js         트레이, 설정, 무인 접속, 입력 처리
  mqtt-relay.js   공개 중계망 연결 (PC ID)
  seal.js         중계망 메시지 암호화
  server.js       인증·시그널링 (중계망/같은 와이파이 공통)
  turn.js, upnp.js  엄격한 통신망 대비 (자동 공유기 열기 + 내장 중계)
  input.js        마우스/키보드 입력 (Windows SendInput)
  host/           PC 창 + 화면 캡처·WebRTC 송신
web/            뷰어 (폰 앱, 다른 PC 접속 창, 같은 와이파이 브라우저 공통)
android-app/    안드로이드 앱 (Capacitor)
.github/        GitHub에 올리면 exe·apk 자동 빌드
```
